Template syntax

    
Templates are C declarations. Pick a struct type as root to place it at an offset, or use the
      template's top-level declarations, which are laid out one after another from the start offset.


#pragma pack(1)            // also pack(push, n), pack(pop); default is natural C alignment
#pragma endian big         // big | little | default (toolbar setting); applies to following fields
#pragma ptrsize 4          // pointer size, default 8
#define COUNT 4

enum Kind : uint16_t { A = 1, B, C = 0x10 };

typedef struct {
    char     magic[4];       // char arrays show as text in the selected code page
    wchar_t  title[8];       // wchar_t / char16_t arrays: UTF-16, char8_t: UTF-8
    uint32_t count;
    enum Kind kind;
    uint8_t  flag : 1, mode : 3;   // bitfields
    union { uint32_t u; float f; };  // anonymous members
    uint16_t items[count];   // sizes may use earlier fields
    uint8_t  pad[count & 1 ? 1 : 0];   // 0/1-sized arrays act as optional fields
    uint32_t next -> Header;   // lazy link: click the offset to decode a Header there
    uint32_t rel  -> Header @ rel + 0x200;   // target computed from the value
} Header;

Header hdr;                          // placed at the start offset
uint8_t data[hdr.count * 2] @ 0x100; // @ places at an absolute offset
uint8_t tail[16] @ FILE_SIZE - 16;   // FILE_SIZE: length of the file

    
Types: char, short, int, long (32 bit), long long, float, double, bool with
      signed/unsigned, int8_t … uint64_t, BYTE WORD DWORD QWORD,
      u8 … u64, s8 … s64, f32, f64, pointers. Expressions support
      + - * / % << >> & | ^ ~ ! == != < > && || ?:,
      sizeof(Type) and hdr.field paths.

    
Links (->) are not decoded until clicked. Following one makes the target type the
      root; ← or Alt+← goes back. A link whose value is 0 is shown as null.
